# Drama Radar v4 Schema

```text
entity occurrence
→ passage
→ context bundle
→ narrative unit
→ report
```

A context bundle preserves 1–3 minutes of transcript around the evidence.

A narrative unit provides:

- headline;
- extractive summary;
- people involved;
- topics;
- development type;
- uncertainty warnings;
- exact timestamped receipt;
- broader context receipt.
