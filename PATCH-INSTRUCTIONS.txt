What changes
------------
1. Source sweeping and transcript downloading are now separate jobs.

2. `python run_radar.py` now performs the safe source sweep only:
   - collect sources
   - index existing transcripts
   - link transcript paths
   - update monthly archives
   - validate

3. `python run_transcripts.py` performs transcript work only:
   - download transcripts
   - rebuild index
   - relink feed
   - update monthly archives
   - validate

4. An IpBlocked or RequestBlocked response creates:
   state\transcript-cooldown.json

   The default cooldown is 12 hours.

5. While cooldown is active, future transcript runs make zero YouTube
   requests and finish successfully.

6. Scheduled transcript windows are configured in settings.json:

   "scheduled_transcript_hours_local": [2, 8, 14, 20]

   Use:
   python run_transcripts.py --scheduled

   Outside the configured local windows, it exits without attempting
   transcripts.

7. Manual testing remains possible:

   python run_transcripts.py

   Force one test despite cooldown:

   python run_transcripts.py --ignore-cooldown

Recommended Task Scheduler setup later
--------------------------------------
SOURCE SWEEP:
- run_sweep.py every 15 minutes or every hour

TRANSCRIPT RUN:
- run_transcripts.py --scheduled
- schedule at 02:00, 08:00, 14:00 and 20:00 local time
